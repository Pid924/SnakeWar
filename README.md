# สงครามงู (Snake War)

เกมงูต่อสู้ เล่นกับคอม หรือเล่น 2 คนบนคีย์บอร์ดเดียวกัน ใครโดนล้อมจนไม่มีทางไปแพ้ เปิดไฟล์ `index.html` ในเบราว์เซอร์ก็เล่นได้ทันที ไม่ต้องติดตั้งอะไร

**เล่นออนไลน์:** https://pid924.github.io/SnakeWar/ (เวอร์ชันเว็บ) · https://pid924.github.io/SnakeWar/3d/ (เวอร์ชัน 3D)

โฟลเดอร์ `godot/` คือโปรเจกต์ Godot ของเวอร์ชัน 3D ส่วน `3d/` คือไฟล์ที่ export เป็นเว็บแล้ว (export ใหม่ได้จาก Godot: Project → Export → Web)

## วิธีเล่น

เลือกโหมดในเมนู: **เล่นกับคอม** (ระดับ ง่าย / กลาง / ยาก), **2 คน** หรือ **ดูคอมสู้กัน** ในโหมดเล่นกับคอม ผู้เล่นใช้ได้ทั้ง W A S D และปุ่มลูกศร

| | ผู้เล่น 1 | ผู้เล่น 2 |
|---|---|---|
| ควบคุม | W A S D | ปุ่มลูกศร |

- `Enter` เริ่มเกม / ไปรอบต่อไป
- `Space` หรือ `P` หยุดพัก, `Esc` กลับเมนู
- บนมือถือ/แท็บเล็ตมีปุ่มกดบนจอให้ทั้งสองฝั่ง

## กติกา

ชนแล้วยังไม่ตาย งูจะติดค้างอยู่กับที่ ถ้าหาทางออกไม่ได้ภายใน 3 วินาทีถึงแพ้รอบนั้น ดังนั้นต้องล้อมปิดทางศัตรูให้ไม่มีช่องไป ถ้าใช้ตัวเองขดล้อมศัตรูได้จนหัวกลับมาชนตัวเอง ศัตรูที่อยู่ข้างในแพ้ทันที ถ้าแพ้พร้อมกันนับเสมอ เลือกได้ว่าต้องชนะ 1, 3 หรือ 5 รอบถึงเป็นแชมป์

## ไอเทม

- 🍎 **แอปเปิ้ล** ตัวเรายาวขึ้น 3 ช่อง
- 🍒 **เชอร์รี่** ศัตรูหดสั้นลง 3 ช่อง
- 🍌 **กล้วย** เก็บไว้ได้ 1 ลูก กด `E` (ผู้เล่น 2 กด `Enter`) เพื่อให้ศัตรูช้าลงครึ่งหนึ่ง 5 วินาที ถ้าเก็บลูกที่สองตอนยังถืออยู่ ศัตรูช้าทันที
