# สงครามงู (Snake War)

เกมงูต่อสู้ 2 ผู้เล่นบนคีย์บอร์ดเดียวกัน ใครชนก่อนแพ้ เปิดไฟล์ `index.html` ในเบราว์เซอร์ก็เล่นได้ทันที ไม่ต้องติดตั้งอะไร

## วิธีเล่น

| | ผู้เล่น 1 | ผู้เล่น 2 |
|---|---|---|
| ควบคุม | W A S D | ปุ่มลูกศร |

- `Enter` เริ่มเกม / ไปรอบต่อไป
- `Space` หรือ `P` หยุดพัก, `Esc` กลับเมนู
- บนมือถือ/แท็บเล็ตมีปุ่มกดบนจอให้ทั้งสองฝั่ง

## กติกา

ชนกำแพง ชนตัวเอง หรือชนตัวอีกฝ่ายก่อน แพ้รอบนั้น ถ้าหัวชนหัวพร้อมกันนับเสมอ เลือกได้ว่าต้องชนะ 1, 3 หรือ 5 รอบถึงเป็นแชมป์

## ไอเทม

- 🍎 **แอปเปิ้ล** ตัวเรายาวขึ้น 3 ช่อง
- 🍒 **เชอร์รี่** ศัตรูหดสั้นลง 3 ช่อง
- 🍌 **กล้วย** ศัตรูช้าลงครึ่งหนึ่ง 5 วินาที
